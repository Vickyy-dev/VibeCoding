# 🛒 Sistema PDV — Projeto Vibe Coding

Sistema web de **Ponto de Venda (PDV) e Controle de Estoque** desenvolvido de forma colaborativa com o apoio de ferramentas de Inteligência Artificial (*Vibe Coding*).

## 🎯 Objetivo
Oferecer uma solução web rápida, intuitiva e funcional para pequenos comércios (mercearias, lanchonetes e lojas de bairro), substituindo o controle manual por uma frente de caixa ágil com baixa automática no estoque.

## 📂 Estrutura do Repositório
- **`01 - Requisitos`**: Documentação de requisitos (RF/RNF), personas e diagramas.
- **`02 - mockup`**: Wireframes e rascunhos visuais das interfaces.
- **`03 - Designer System`**: Paleta de cores, tipografia e padrões de componentes.
- **`04 - Prompt`**: Registo dos melhores prompts utilizados na geração de código com IA.
- **`05 - Frontend`**: Código da interface web (HTML, CSS, JavaScript / React).
- **`06 - Backend`**: Servidor, regras de negócio da API e banco de dados (Node.js / Express).
- **`07 - Testes`**: Relatórios de QA, registo de bugs e métricas de desenvolvimento.
